# 🤖 Multi-Model AI Chatbot using Node.js & OpenRouter API

AI Chatbot with **automatic model fallback** using the OpenRouter API.  
This project is a simple AI Chat Web App built using **Node.js + Express + EJS**.

If one AI model fails (rate limit / busy), the server automatically switches to the next model in the priority list.

---

## 🚀 Features
- Express.js backend
- EJS frontend UI
- OpenRouter API integration
- Automatic fallback between multiple models
- Axios for API requests
- Clean folder structure

---

## 📦 Models Used (Priority Order)
1. DeepSeek R1  
2. DeepSeek Chat V3  
3. Llama-4 Maverick  
4. Grok 4 Fast
